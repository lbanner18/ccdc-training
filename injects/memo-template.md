# Inject memo template

This is the memo structure the team actually uses. Match it exactly — an
unfamiliar shape costs points before a grader reads a word of your content.

```text
INTEROFFICE MEMORANDUM

To:      <the role the inject came from, e.g. "Networks Operation Manager">
From:    Team XX
Date:    <competition date>
Subject: <the inject name, copied exactly>

Summary: <one or two sentences, non-technical, stating what was asked and
         what you did about it>

<body: answer every numbered request in the inject, in the inject's order>

<evidence: screenshots, tables, or the artifact the inject asked for>

If there are any concerns, questions, or clarifications, please do not
hesitate to reach out.

With Regards,
Team XX
```

## Rules that cost points when broken

- **Team number is the only identifying information.** No names, no usernames,
  no hostnames that identify you.
- **The subject line is the inject name, copied exactly.** Graders sort by it.
- **Answer every explicit request.** Injects number their asks; if the inject
  has three numbered items, the memo has three answers. A partially answered
  inject scores as a partial inject.
- **Non-technical language.** The reader is a COO or an IT Director, not you.
  State the risk and the action, not the command you ran.
- **If the inject asks for screenshots on each server, it means each server.**
  A missing box is a missing deliverable.

## Before you submit

- [ ] Subject matches the inject name character for character
- [ ] Team number present, personal names absent
- [ ] Every numbered request has a visible answer
- [ ] Every artifact the Deliverables section named is attached
- [ ] Read once out loud for jargon
