# 15-minute inject drill

Run a timer. Use only the memo template and the evidence you have already
collected.

1. Minute 0–2: read the inject twice and underline every explicit request.
2. Minute 2–5: write the situation and impact in plain language.
3. Minute 5–10: answer every request with an owner, time, and status.
4. Minute 10–13: check the subject line and team number.
5. Minute 13–15: remove jargon, unsupported claims, and unanswered questions.

The final memo should be understandable to a non-technical executive without
losing the concrete next action.
